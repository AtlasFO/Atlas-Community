# Demo / example cases

Bundled investigation studies for browsing finished runs and learning Atlas.

- **Browse:** `./dashboard.sh --demo` (or `--cases-root ~/Atlas/demo-cases`)
- **Re-run:** fetch evidence from the sources in [docs/datasets.md](../docs/datasets.md), then  
  `bin/atlas run --case ~/Atlas/demo-cases/<name> -q "..."`

These are **not** customer investigations. Production cases live in `~/cases/`.
